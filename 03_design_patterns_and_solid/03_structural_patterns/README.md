# 🌉 Structural Design Patterns in Python

## 📖 Introduction
Structural design patterns explain how to **assemble objects and classes into larger, flexible structures** while keeping these structures flexible and efficient. They focus on how classes and objects are composed to form larger components.

---

## 🗺️ Patterns in this Section

| Pattern | Intent / Purpose | Real-World Use Case |
|---|---|---|
| **[01. Adapter](./01_adapter/)** | Convert the interface of a class into another interface clients expect. | Integrating legacy third-party payment/analytics SDKs with new API models. |
| **[02. Facade](./02_facade/)** | Provide a unified, simple interface to a complex subsystem. | Video conversion engine, Cloud infrastructure deployment orchestrator. |
| **[03. Proxy](./03_proxy/)** | Provide a surrogate or placeholder for another object to control access to it. | Lazy loading heavy resources, Caching proxy, Security/Permission checks. |
| **[04. Decorator](./04_decorator/)** | Attach additional responsibilities to an object dynamically (Wrapper). | Adding logging, encryption, or compression to data streams. |
| **[05. Composite](./05_composite/)** | Compose objects into tree structures to represent part-whole hierarchies. | File systems (Files & Folders), UI view hierarchies, Organization charts. |
| **[06. Flyweight & Bridge](./06_flyweight_and_bridge/)** | Shared memory reduction for thousands of objects (Flyweight) and decoupling abstraction from implementation (Bridge). | Particle systems in gaming, Multi-platform database drivers. |
